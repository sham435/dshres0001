=== Export route bug fix ===

Bug: GET /admin/marks/export returned 500 with "Method MarkController::show does not exist".

Root cause: Route ordering in routes/web.php (admin group). The line:
    Route::resource('marks', MarkController::class);
creates GET /admin/marks/{mark} → MarkController@show. Since resource()
was defined BEFORE the explicit export route:
    Route::get('/marks/export', ...);
the URL "export" was matched as {mark} parameter by the resource route,
causing Laravel to dispatch to MarkController@show('export'), which
doesn't exist.

Fix: Moved import/export routes BEFORE Route::resource('marks'):
    Route::post('/marks/import', ...)     // now at line 42
    Route::get('/marks/export', ...)      // now at line 43
    Route::resource('marks', ...)         // now at line 44

Laravel matches routes top-to-bottom, so explicit literal routes take
priority over parameterized resource routes when defined first.
