School Management System — Blueprint==>
1. Overview
- Framework: Laravel 8 (PHP), Bootstrap UI via laravel/ui, Excel via maatwebsite/excel, PDFs via barryvdh/laravel-dompdf
- DB: MySQL/MariaDB, database school_management
- Languages: English / Tamil / Sinhala (session locale switcher, Noto fonts)
- Server: env -u DATABASE_URL php -d upload_max_filesize=100M -d post_max_size=100M artisan serve --host=127.0.0.1 --port=8000
- Login: email + password cj for all test users
2. Roles (7) & Access Map
Role	Prefix	Can access
super_admin	admin.*	Everything (full CRUD all resources + settings + student-marks import/export)
admin	admin.*	Same as super_admin (delete restricted by policy intent)
teacher	teacher.*	Dashboard, marks (index/create/store/edit/update), timetable (view), study-materials (full exc. show + download), profile
student	student.*	Dashboard, marks, marksheet, timetable, payments, books, notices, profile
parent	parent.*	Dashboard, child's marksheet (marksheet/{child}, ownership-checked), timetable (timetable/{child?}), payments, books, notices, profile
accountant	accountant.*	Dashboard, payments CRUD + receipt
librarian	librarian.*	Dashboard, books CRUD
3. Database Schema (16 tables)
- roles (id, name, display_name, description)
- users (+ role_id, username, phone, address, dob, gender)
- classes, subjects (→ class_id), exams (→ class_id, exam_date)
- marks (→ exam/student/subject, marks_obtained, total_marks, grade NOT NULL, remarks)
- books (author + available_quantity NOT NULL)
- payments (→ student, fee_type, amount, paid_amount=0, due_date NOT NULL, status enum paid/unpaid/partial)
- notices (title, content, notice_date, → posted_by)
- timetables (→ class/subject/teacher, day_of_week, start/end_time, room_number)
- study_materials (title, description, file_path, → subject/teacher)
- settings, student_marks (flat import table, unique sm_unique)
- Pivots: class_student (class_id, student_id, academic_year), teacher_class (teacher/class/subject, is_class_teacher), student_parent (parent_id, student_id)
4. Key Controllers & Rules
- DashboardController — role redirect + per-role counters (myMarks/notices/payments/booksAvailable, recentNotices/totalPayments, availableBooks/recentBooks)
- MarkController — class filter via student.classes pivot; store/update validate marks_obtained/total_marks, auto-grade A≥75/B≥65/C≥55/S≥40/F; parent ownership enforced; teacher redirects stay under teacher.*
- TimetableController — validates subject_id/teacher_id/day_of_week; create/edit supplied with subjects + teachers
- StudyMaterialController — no class_id; shared admin/teacher views via $routePrefix; download with 404 guard
- BookController — author + available_quantity required
- StudentMarkController — search/filter + Excel import/export (routes defined before resource('marks'))
- CheckRole middleware — role:... gate, 403 otherwise
